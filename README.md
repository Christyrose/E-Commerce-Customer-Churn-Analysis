# E-Commerce Customer Churn Analysis

A MySQL project analyzing customer churn, purchasing behavior, satisfaction, complaints, and returns in an e-commerce dataset.

## Tools Used

- MySQL
- MySQL Workbench

## Project Includes

- Data cleaning and missing-value handling
- Data standardization
- Customer churn analysis
- Customer satisfaction and complaint analysis
- Payment and purchasing behavior analysis
- Customer returns analysis
- SQL queries using filtering, aggregation, grouping, joins, and subqueries

## Analysis

The project answers 17 business questions related to:

- Customer churn
- Customer tenure
- Cashback and order behavior
- Payment methods
- Product categories
- Customer complaints
- Satisfaction levels
- Coupon usage
- Warehouse distance
- Customer returns

## Files

- `ecommerce_customer_churn_analysis.sql` — Complete SQL script containing the database setup, data cleaning, transformations, analysis queries, and returns analysis.

## Key Skills Demonstrated

- SQL Data Cleaning
- Data Transformation
- Aggregate Functions
- GROUP BY and HAVING
- CASE Statements
- Subqueries
- JOINs
- Business Data Analysis
